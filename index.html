Waterfall

Run the waterfall query once in Query Studio and paste all its result rows below (each row is a combo and a count n). Each step then shows how many people it removes and how many are left.

After that, everything updates without running the query again: arrows change the step order and the switch turns a step off to see the audience without it (what-if).

What each flag checks

1 means the person passes the check, 0 means they fail it. Required flags decide passed. Detail flags split a joined table into one flag per condition. Exclusions (NOT IN / NOT EXISTS) are turned into lookups and filtered out, so excluded people are left out of the results and don't count as failures.
